Data Deletion Instructions

Last updated: 3 October 2026

LH Social Scheduler has no server of its own. All data it holds is stored only on the owner's computer, so deleting it is done in two steps: revoke the app's access on each platform, then delete the local files.

1. Revoke access on each platform

Facebook and Instagram

Open Facebook → Settings and privacy → Settings → Business integrations (or Apps and websites), select LH Social Scheduler and choose Remove.

YouTube / Google

Go to Google security settings → Third-party apps, select LH Social Scheduler and choose Remove access.

TikTok

In the TikTok app open Settings and privacy → Security → Apps and services permissions, select LH Social Scheduler and choose Remove access.

2. Delete local data

On the computer running the app, delete the app's tokens and analytics folders. This removes every stored sign-in token and statistic.

Questions

Requests or questions about data deletion can be raised on the app's GitHub issues page.
